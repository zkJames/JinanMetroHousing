# 济南地铁地图

地图展示地铁站与出入口，支持小区搜索、地图测距和查看地铁线路图。站点数据为随项目提供的快照，实际线路与开通状态请以官方信息为准。

## 运行

1. 申请高德地图 Web 端 JS API 的 Key 和安全密钥；如需小区搜索，另准备 Web 服务 Key，并确认相应接口权限。
2. 将 `config.example.js` 复制为 `config.local.js`，填写自己的配置。该文件已列入 `.gitignore`，请勿提交或分享。
3. 在项目目录运行 `python -m http.server 8000`，浏览器访问 `http://localhost:8000/jinan-map.html`。实际可用性取决于高德平台应用的域名、安全设置和网络。

项目未预置楼盘清单。搜索时输入的内容仅用于本次地图查询。前端使用的 JS API Key 会暴露在浏览器中，请按高德平台要求限制来源；Web 服务 Key 也由浏览器调用，应做好来源和额度限制。生产环境建议通过服务端代理保护 Web 服务 Key。
