# 济南地铁房地图（安卓平板 PWA 版）

地图展示济南地铁站、出入口、线路及小区搜索，并针对**华为 MatePad 12.2 英寸**（横屏优先，兼容竖屏）增加手指画线测距、楼盘收藏、最近搜索、图层开关、测距保存、备份导入导出和桌面快捷启动。保留原有地铁快照数据和地图功能。

> 数据说明：地铁站点与线路轨迹为随仓库提供的高德数据快照。规划/在建参考路线（如 7 号线）的状态和走向以官方最新信息为准。本应用只供个人辅助查看，不作为房产购买或交通规划的唯一依据。

## 使用方式

平板推荐横屏。点击「手指画线」后，在地图上按住手指拖出一段轨迹，松手完成当前段，可以继续画下一段。点击「完成 / 浏览」恢复正常拖动和双指缩放。也可以选择「点选折线」，逐点测量折线距离；选择「两点步行」，在高德上计算实际步行路线。

按钮支持撤销、重做（手绘和点选）、保存与清除。保存的测距可从顶部「测距记录」找回。收藏、搜索历史、图层和地图视角自动保存在平板浏览器本地，备份入口可导出/导入 JSON。清除浏览器数据可能清除这些记录，应按需备份。

## Vercel 部署（推荐给个人自用，不需要域名）

仓库已使用静态 HTML/CSS/JS，不需要 React、Vue 或新的构建命令。Vercel 项目连接 GitHub 仓库，Framework Preset 使用 **Other**，Root Directory 使用仓库根目录；使用 \`main\` 为生产分支，功能开发分支自动生成预览部署。

先在 Vercel 项目 **Settings → Environment Variables** 设置以下三个环境变量，并同时应用于 Preview 和 Production：

| 变量 | 来源 | 说明 |
| --- | --- | --- |
| \`AMAP_JS_API_KEY\` | 高德 Web端(JS API) Key | 浏览器仍会收到该公开标识；应在高德控制台限制允许使用的来源/配额 |
| \`AMAP_SECURITY_JS_CODE\` | 上述 Key 对应的安全密钥 | **仅服务端**使用，不进入前端或 GitHub |
| \`AMAP_WEB_SERVICE_KEY\` | 高德 Web 服务 Key | **仅服务端**使用，\`/api/poi\` 搜索代理调用 |

> 变量名区分大小写；修改环境变量后需要重新部署才能生效。不要在聊天里提供 Key 或安全密钥，也不要提交 \`config.local.js\`。某些新高德 Key 需要先在高德开放平台开通对应 API 权限。

前端 \`/api/config\` 只下发 JSAPI Key；高德的安全密钥留在 Vercel Functions，并通过官方约定的 \`/_AMapService\` 前缀代理。小区搜索 \`/api/poi\` 独立代理，不把 Web 服务 Key 暴露给浏览器。

**限制：** Vercel 的 \`*.vercel.app\` 地址在中国大陆部分运营商/网络下可能不稳定，不能保证华为平板在所有网络都可访问。完成部署后，请分别用平板 Wi‑Fi 和手机热点测试地图、楼盘搜索与步行规划。PWA 缓存**不包含高德底图**，离线时只能有限展示本地页面/数据，不能保证在线地图功能。

### 华为平板桌面快捷方式

用华为浏览器打开正式 HTTPS 地址，选择浏览器菜单中的「添加到桌面」（具体名称会随系统版本变化）；部分系统会以快应用/网页快捷方式呈现。请在平板上验证是否是独立窗口，不要把所有华为系统版本都当作标准 Chromium PWA。

## 本地开发

1. 从 \`main\` 或开发分支拉取仓库。
2. 复制 \`config.example.js\` 为 \`config.local.js\`，填写本地高德 JS API Key、安全密钥和 Web 服务 Key。该文件已在 \`.gitignore\` 中。
3. 执行 \`python -m http.server 8000\`，访问 \`http://localhost:8000/jinan-map.html\`。本地 \`/api/config\` 与 \`/api/poi\` 不存在，代码会使用本地配置直接访问高德，仅限个人开发；正式网站使用 Vercel 服务端代理。
4. 运行 \`node --test tests/check.mjs\` 执行零依赖自检（需要 Node.js）。

## 架构与缓存

- \`jinan-map.html\`：现有地图主体和查询/渲染逻辑。
- \`css/tablet.css\`：平板横竖屏与大尺寸触控布局。
- \`js/tablet-measure.js\`：手指自由画线、点选折线、步行测距，基于高德坐标计算。
- \`js/tablet-ui.js\`：抽屉式收藏/历史/图层/备份和地图缩放工具。
- \`js/storage.js\`：有限量本地保存和导入数据校验，不需要账户或服务器数据库。
- \`sw.js\`：只缓存应用自身静态资源；网页导航优先联网，失败时回退缓存。
- \`api/*.mjs\`：Vercel Functions，仅负责关键 API 配置和安全代理，不新增业务数据库。

### 已知约束与验收

手绘得到的是**沿手指轨迹的几何距离**，并非真实道路步行距离；请使用「两点步行」计算路线距离。绘制时会锁住地图拖动以避免误触，返回浏览模式后恢复拖动/缩放。

完成后需要在真实 MatePad 12.2 上测试横屏、竖屏、触摸绘制、多点折线、点击地铁站、楼盘搜索、步行规划、收藏恢复、断网提示和桌面快捷启动。尤其要确认高德 Key 权限和 Vercel 默认域名在所在网络可用。
